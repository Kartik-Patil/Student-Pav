STUDENT PAVILION — DATABASE-FREE LANDING PAGE

OPEN IT
1. Extract the ZIP first (do not open index.html inside the ZIP).
2. Open the student-pavilion folder.
3. Double-click index.html to open it in Chrome, Edge or Firefox.

No PHP, MySQL, database import or XAMPP is needed.
The layout, gallery and menu work locally. Internet is needed for Google
Fonts and the Google Map. Without internet, fallback fonts are used.

OPTIONAL XAMPP
Put this student-pavilion folder in C:\xampp\htdocs and start Apache only.
Open http://localhost/student-pavilion/index.html
Do not merge it into the previous PHP version: use a fresh folder, or
move the previous folder out of htdocs first. MySQL can stay stopped.

ENQUIRIES AND EDITING
Email Us opens the visitor's email application. Sending the email requires
an email app/account; the website does not send or save it automatically.
There is no admin panel, login, upload system or saved enquiry inbox.
All text and prices are in index.html. Open it in a text editor to change
content. Photos are in assets/images; replace them using the same names.
Keep the assets folder beside index.html.

HOSTING
Upload index.html, favicon.ico and assets to your website's public folder.
You do not need a database or PHP hosting for this version.
Once your domain is decided, add its real canonical URL and social-image
URLs to the page head. No domain has been invented for this local copy.
